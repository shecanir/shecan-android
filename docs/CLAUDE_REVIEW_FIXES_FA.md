## بررسی‌ها و حدود نتیجه

تست‌های بازسازی state واقعی FragmentManager، پذیرش ریشهٔ سیستم و ریشهٔ همراه اپ و رد گواهی نامعتبر، شروع سیستمی سرویس VPN، حفظ پیکربندی آپدیت اجباری، ذخیرهٔ تنظیم بوت، انتخاب سرویس و حذف دامنه از لاگ اضافه شدند. build هر سه flavor، ۵۵ تست برای هر flavor (مجموعاً ۱۶۵ تست) و build نسخهٔ release سایت با موفقیت تمام شدند. بررسی XML کامپایل‌شدهٔ shortcut و permissionهای manifest نیز موفق بود. برای دریافت وابستگی‌های مسدودشدهٔ Google Maven از mirror موقت خارج از ریپو استفاده شد.

CI روی GitHub در این بررسی اجرا نشده است. تست دستگاه واقعی برای OTP، اتصال پس از reboot و Always-on، و خرید با حساب آزمایشی مارکت هنوز انجام نشده است. شکن VPN محلی برای DNS است؛ گزینهٔ سیستم «Block connections without VPN» برای مسیریابی کامل همهٔ ترافیک نیاز به بررسی جداگانه دارد.

گزارش ارسالی جزئیات M1 تا M8، M16 و G3 تا G8 را نداشت؛ قرارداد monitoring و پاسخ POST لاگ‌ها از این نقل‌قول قابل تعیین نیست و تغییر داده نشد. تغییر نسخهٔ موجود کاربر (`2.4.8` / `10298`) حفظ شد.
